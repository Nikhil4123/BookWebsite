## ✨ Overview

BookWebsite is a comprehensive full-stack web application designed to provide book enthusiasts with an exceptional online book shopping experience. Built with modern technologies and featuring a beautiful, responsive design, the platform offers everything from browsing and purchasing books to engaging with a community of fellow readers.

## 🎯 Features

### 📖 **Book Management**
- **Extensive Catalog** - Browse through thousands of books across multiple genres
- **Advanced Search** - Find books by title, author, genre, or ISBN
- **Detailed Information** - View comprehensive book details, reviews, and ratings
- **Book Reviews** - Read and write reviews for your favorite books

### 🛒 **E-commerce Functionality**
- **Shopping Cart** - Add books to cart and manage your selections
- **Secure Checkout** - Safe and secure payment processing
- **Order Management** - Track your orders and purchase history
- **User Accounts** - Create accounts to save preferences and order history

### 👥 **Social Features**
- **Community Hub** - Connect with other book lovers
- **Book Clubs** - Join or create book reading clubs
- **Social Posts** - Share thoughts and recommendations
- **User Profiles** - Customize your reading profile

### 💻 **Modern User Experience**
- **Responsive Design** - Optimized for all devices and screen sizes
- **Dark/Light Mode** - Choose your preferred theme
- **Smooth Animations** - Enhanced with Framer Motion animations
- **Fast Loading** - Optimized performance with Vite build system

## 🛠️ Tech Stack

### **Frontend**
- **⚛️ React 18** - Modern UI library with hooks and functional components
- **⚡ Vite** - Fast build tool and development server
- **🎨 Tailwind CSS** - Utility-first CSS framework for styling
- **🎭 Framer Motion** - Smooth animations and transitions
- **🔄 Redux Toolkit** - State management for complex app state
- **🧭 React Router** - Client-side routing and navigation

### **Backend**
- **🟢 Node.js** - JavaScript runtime for server-side development
- **🚀 Express.js** - Web application framework for Node.js
- **🍃 MongoDB** - NoSQL database for flexible data storage
- **🔐 JWT** - JSON Web Tokens for secure authentication
- **🔒 bcrypt** - Password hashing for enhanced security
- **🔌 Socket.io** - Real-time communication features

## 📦 Installation

### Prerequisites
- **Node.js** (v18 or higher)
- **npm** or **yarn**
- **MongoDB** (local installation or cloud instance)

### 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/Pavan0228/BookWebsite.git
   cd BookWebsite
   ```

2. **Install dependencies**
   ```bash
   # Install root dependencies
   npm install

   # Install frontend dependencies
   cd frontend
   npm install

   # Install backend dependencies
   cd ../backend
   npm install
   ```

3. **Environment Setup**
   ```bash
   # Create environment file for backend
   cd backend
   cp .env.example .env
   # Edit .env with your MongoDB connection string and other config
   ```

4. **Start the application**
   ```bash
   # Start backend server (from backend directory)
   npm start

   # Start frontend development server (from frontend directory)
   cd ../frontend
   npm run dev
   ```

5. **Access the application**
   - Frontend: `http://localhost:5173`
   - Backend API: `http://localhost:3000` (or your configured port)
